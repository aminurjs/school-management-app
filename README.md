# School Management Web Application

## Overview
This is a **School Management Web Application** frontend built using [Next.js](https://nextjs.org/) and [ShadCN UI](https://shadcn.dev/). The application features a light and dark theme with a toggle functionality for seamless user experience. It leverages the Next.js App Router and organizes code within the `src` directory for better structure and maintainability.

---

## Features
- **Light/Dark Theme Toggle**: Switch between light and dark modes.
- **Student Management**: Add, edit, view, and delete student details.
- **Teacher Management**: Manage teacher profiles and their schedules.
- **Class Scheduling**: Create and manage class timetables.
- **Dashboard**: Overview of school operations and analytics.
- **Responsive Design**: Optimized for both desktop and mobile devices.

---

## Technologies Used
- **Next.js**: Framework for building React applications with server-side rendering (SSR) and static site generation (SSG).
- **ShadCN UI**: For pre-built, customizable UI components.
- **TypeScript**: Adds static typing for better code quality and maintainability.
- **Tailwind CSS**: For styling and ensuring responsiveness.

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aminurjs/school-management-app
   ```

2. **Navigate to the project directory:**
   ```bash
   cd school-management-app/next-dashboard-ui
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Set up environment variables:**
   Create a `.env.local` file in the root directory and add the required variables (refer to `.env.example` if available).

5. **Run the development server:**
   ```bash
   npm run dev
   ```

6. **Open the application in your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).
